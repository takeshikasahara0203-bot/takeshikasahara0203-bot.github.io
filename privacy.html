プライバシーポリシー / Privacy Policy

1. 運営者 / Operator

本アプリケーション「Hermes Agent Tools」は、個人である Takeshi Kasahara (連絡先: takeshikasahara0203@gmail.com)が運営するものであり、法人・組織のものではありません。

2. アクセスするデータ / Data Accessed

本アプリケーションは、開発者本人の Google アカウントにOAuth 2.0で接続し、以下のデータにアクセスします。

  • Gmail: メッセージの読み取り、ラベルの付与・管理 (gmail.modify)
  • Google Drive / Docs / Spreadsheets: メタデータおよび内容の読み取り (readonly)

3. データの利用目的 / Purpose

取得したデータは、開発者個人のローカルマシン上でのメール整理・情報収集自動化など、 本人自身の業務効率化のためにのみ使用します。データの販売、広告利用、第三者への提供・譲渡は一切行いません。

4. データの保存 / Storage

アクセストークン等の認証情報および取得データはすべて開発者個人のローカル環境に保存され、 外部サーバーには保存されません。

5. データの削除 / Retention & Deletion

Google アカウント側の権限は、Google アカウントの 「第三者の接続済みアプリ」設定からいつでも取り消せます。 取り消し後、ローカルに保存されたトークンも速やかに削除されます。

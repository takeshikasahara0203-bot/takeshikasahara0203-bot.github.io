Hermes Agent Tools

このサイトについて / About

「Hermes Agent Tools」は、Takeshi Kasahara 個人がローカル環境で利用するための 自動化ツール(OAuth クライアント)です。本人自身の Google アカウントに対して、 Gmail・Google Drive・Docs・Spreadsheets の読み取りおよび Gmail のラベル管理などを行う目的で 接続します。第三者へのデータ提供や商用サービスは行っていません。

Hermes Agent Tools is a personal, non-commercial OAuth client used locally by its developer to manage his own Google account data (Gmail, Drive, Docs, Sheets).
